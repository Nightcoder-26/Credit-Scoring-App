# 📂 data/ — Dataset Folder

Place your dataset file here. The app supports two options:

---

## ✅ Option A — Use Your Own CSV (Recommended if you have a file)

**Drop your CSV here and rename it to:**
```
data/german_credit.csv
```

### Required column:
| Column | Values |
|--------|--------|
| `credit_risk` | `1` = Creditworthy, `0` = Default |

### Accepted target column name aliases (auto-detected):
`target`, `label`, `class`, `default`, `creditworthy`, `good_bad`

### Accepted target value aliases (auto-detected):
`good`, `bad`, `yes`, `no`, `1`, `0`, `2` (UCI convention)

### Optional feature columns (any subset works):
```
age, duration, credit_amount, installment_rate, residence_since,
existing_credits, num_dependents, checking_account, savings_account,
credit_history, employment, housing, job, purpose, personal_status,
other_debtors, property, other_installments, telephone, foreign_worker
```

---

## ✅ Option B — Auto-Download UCI Dataset (No file needed)

If no CSV is present, the app **automatically downloads** the German Credit Dataset
from the UCI ML Repository:

```
https://archive.ics.uci.edu/ml/machine-learning-databases/statlog/german/german.data
```

Saved as `data/german.data` (1,000 samples, 20 features).

---

## 📥 Where to Get the Dataset

| Source | Link |
|--------|------|
| UCI German Credit | https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data |
| Kaggle German Credit | https://www.kaggle.com/datasets/uciml/german-credit |
| Give Me Some Credit | https://www.kaggle.com/c/GiveMeSomeCredit |

For Kaggle datasets, rename the target column to `credit_risk` with values `0`/`1`.

---

## 🗂️ Files in this folder after training:
```
data/
├── german_credit.csv          ← YOUR FILE (if using Option A)
├── german.data                ← Auto-downloaded UCI file (Option B)
├── german_credit_cleaned.csv  ← Cleaned version (generated by train_model.py)
└── model_comparison.csv       ← Model metrics table (generated by train_model.py)
```
